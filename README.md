## What I'm Building

### PARSE — *AI pipeline for business analysis*

You describe a business in plain text. PARSE returns a structured breakdown, ranked recommendations, a solution blueprint with a generated architecture diagram, and an implementation document you can export.

Five stages, five endpoints, each one independently testable — `ingest` → `structure` → `recommend` → `solution` → `export`.

- **Stack** — Python, FastAPI, Pydantic, Gemini API
- **Status** — backend complete and tested, frontend in progress
- **Built by** — me, alone. It started as a four-person hackathon project called Chaos2Commit. The team dissolved. I kept building.

The interesting problem wasn't the API calls. It was forcing a non-deterministic model into a schema strict enough that the next stage in the pipeline could rely on it.

### Phishing Domain Detector — *SIH 2026*

An ML classifier for detecting phishing domains, built for Smart India Hackathon problem statement CHA-46. Cleared the university selection round with a four-person team. Currently in the design and dataset stage — no code to show yet, and I'd rather say that than pad this section.

### Foundations

Working through Harvard's CS50 in C — through Week 5, psets 0–3 done. Not a portfolio project, just the reason I understand what a pointer is.
